# P2 Prompts

## Prompt 1 — P2 expression trees

```text
Create 66/code/66_q2.pl and implement only expression(+Numbers, -Tree, -Value) for problem P2. It enumerates, on backtracking, every binary expression tree whose leaves are exactly Numbers in the given order (split the list into two non-empty parts with append/3), with operators +, -, \* and /. Represent leaves as num(N) and nodes as op(Op, Left, Right). Evaluate with integer arithmetic while building: a division node is allowed only when the divisor is non-zero and the division is exact, at every level of the tree. Intermediate values may be negative. Do not build strings or parse anything. Check that [1,2,3] yields 2 tree shapes x 16 operator choices minus any rejected divisions.
```

Result: Added expression/3 with integer evaluation and division checks at every node. SWI-Prolog returned 20 distinct trees for [1,2,3], with 10 per shape. The trees and values matched independent checks across 343 input lists.
