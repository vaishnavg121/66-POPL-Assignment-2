## Prompt 1 — P1 clues 1–8

```text
Create 66/code/66_q1.pl and implement only clue/2 for clues 1 to 8 of problem P1 in the handout. A Solution is a list of four terms p(Name, Dept, Lang, Project) in the order 'Alex', 'Ben', 'Carla', 'Dana', using exactly the atoms given in the handout (note 'c++' and 'AI' are quoted). Write one clause clue(N, Solution) per clue that succeeds exactly when clue N holds in a fully instantiated Solution. Locate friends by attribute with member/2 and only compare bound values. Put the English clue in a comment directly above each clause. Load the file in swipl to confirm it compiles without warnings.
```

Result: Implemented clue/2 for clues 1–8. SWI-Prolog 9.2.9 loaded the file without warnings, and all eight clues matched the handout across all 13,824 valid arrangements.
