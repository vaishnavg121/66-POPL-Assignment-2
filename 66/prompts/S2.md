```text
Create 66/code/66_q4.rkt starting with #lang racket/base and implement only (my-length lst), which returns the number of top-level elements of a list. Use only the built-ins allowed by the handout's Scheme rules and make it tail-recursive with a named let so it handles 10,000-element lists.
```
