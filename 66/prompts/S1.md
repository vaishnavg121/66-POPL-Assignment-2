# S1 Prompts

## Prompt 1 — S1.a print inorder

```text
Create 66/code/66_q3.rkt starting with #lang racket/base and implement only (print-inorder tree) for S1.a, plus any helpers it needs. A tree is () or (value left right). Print the inorder list of values on one line with display, then newline. Use only the built-ins allowed by the handout's Scheme rules (so no append or reverse; write my-reverse if needed), pass all state through arguments, visit the left subtree before the right, and use an accumulator rather than repeated appending. The file must contain only definitions. Check it prints (1 2 3 4 5 6 7) for t1 from the handout and () for the empty tree.
```

Result: Added print-inorder with left-first accumulator traversal. Racket 8.18 verified silent loading and exact output for t1, the empty tree, the symbol tree, and both 10,000-node skewed trees.
